# Dress Collection Website

A responsive Dress Collection landing page built with HTML, CSS, JavaScript and Bootstrap 5.

## Run it
1. Extract `dress_collection_website.zip`.
2. Keep the `assets` folder beside `index.html`.
3. Open `index.html` in a browser. Bootstrap and Google Fonts load from their CDNs, so an internet connection is needed for those external resources.

## Included features
- Profile image and Dress Collection logo in the header
- Responsive navigation and collection search
- Four collection category tiles
- Three featured product cards
- Contact form layout with email, Facebook and phone links
- Category selection and featured-item filtering

## Customize
- Replace the contact email and phone placeholders in `index.html` with your real contact details.
- The contact form currently validates in the browser and displays a confirmation message; connect a form backend or email service to receive submissions.
- Change product names and images by editing the relevant cards and files in `assets/`.
